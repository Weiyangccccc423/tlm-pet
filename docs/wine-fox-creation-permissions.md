## 与本项目有关的事实

README 的二创展示表中已有 [酒狐桌宠](https://www.xiaoheihe.cn/app/bbs/link/47417015b536)，

同表有“酒狐 3D 模型打印售卖”，特别注明“已授权”；不能将该个案许可推广到其他项目。

角色与资源由多位作者参与制作。默认大正女仆酒狐的名单包括完美冻结（模型原作）、
星屑海螺（动画原作及部分模型修改）、白帆小喵（新版材质）等。
实际发布时应按采用的模型、动画、材质版本保留相应名单，而不只署名仓库维护者。

README 写明角色初始设定参考 AI 生成的人设图，另有 AI 设定图与 AI 小漫画。
本次读取的 README 没有明确列出 AI 聊天、模型训练、LoRA 或语音克隆的专门许可或禁令。
这些用途不能仅凭“设定图使用了 AI”认定已获许可。

README 末尾所称定制表情包“完全商业化授权”，描述的是酒石酸菌委托画师取得的授权，
不能直接认定第三方也可将表情包商业化使用。模型声明也不能代替配音、声线等资源的授权。

## 架构讨论的建议

以下是工程建议，不是作者原文要求：

- 将通用 Agent 程序、存档记忆读取与酒狐角色资源包分开管理。
- 酒狐资源包保存来源链接、具体作者、许可和修改说明，模型衍生资源按 CC BY-NC-SA 4.0 发布。
- 独立程序代码的许可单独标注；CC 的相同方式共享不自动等于所有独立代码必须采用 CC。
  实际打包与商业使用仍需结合采用的资源和发布方式判断，拆包不能绕过非商业条件。
- 发布默认先以非商业酒狐桌宠为目标；涉及售卖、订阅、广告或付费角色包时，单独核实作者许可。
- Agent 的角色设定与内容行为需要考虑作者声明中的内容限制，开放式聊天也属于产品行为。
